# MasyaLink v1.6

Near-release UI/media patch.

## Highlights
- Full pink-first visual refresh with smooth Compose animations.
- Chat style presets in Settings: Pink cloud, Lavender night, Milk strawberry, Sakura paper.
- Peer avatar and display name in the chat header.
- Inline image preview.
- Inline video preview with adaptive rounded player.
- Voice messages with automatic loading, play/pause, waveform, progress animation.
- Voice recording strip with animated waves.
- Circular video notes recorded through Android camera capture and displayed as round video messages.
- Attach menu: image, gallery video, circle video, file.

## Server
Run `server/sql/SERVER_PATCH_CURRENT.sql` in Supabase before testing APK v1.6.

## Push
Run `push_force.bat` from the project root.
